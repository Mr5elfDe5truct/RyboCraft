Install RyboCraft

Drag RyboCraft.app onto Applications.

Updating an older installation

1. Quit the app.
2. Drag RyboCraft.app from this disk image onto Applications and choose Replace.

Some earlier releases were installed as SolidCraft.app. Move that one to the Trash
once RyboCraft.app is in Applications, and replace any Dock shortcut with the
old name (open RyboCraft.app, then choose Options > Keep in Dock).

Designs saved as .rybocraft or .solidcraft still open, and RyboCraft copies
your settings and recovery files from the old SolidCraft folder on its first
launch. New designs are saved as .sc.
