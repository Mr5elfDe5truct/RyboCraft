# Samples

The start page lists the built-in samples by group (`rybocraft_engine::sample::samples`). Each
sample is a script of ordinary commands, so opening one gives an editable design with its
parameters and timeline.

- The first six scripts are written in `crates/engine/src/sample.rs`; the others are files in
  `scripts/`, in the form `rybocraft-cli run` takes (`{"commands": [...]}`), included by
  `sample.rs`. Try one with `rybocraft-cli snapshot scripts/<name>.json --out shot.png`.
- The 240 × 150 PNGs in `exports/`, one per sample in list order, are generated by RyboCraft's
  thumbnail renderer from those scripts, using the same isometric camera as Recent. They are
  embedded by `home.rs`, so displaying Home does not evaluate sample geometry or read pixels back
  from the GPU. Selecting a sample builds its editable design through the normal commands.
- The controller faceplates are starting shapes, not measured parts: check them against your own
  controller before printing.

Regenerate after adding or changing a sample script:

```sh
cargo test --profile ci -p rybocraft-ui-egui --lib home::tests::regenerate_sample_thumbnails -- --ignored --exact --nocapture
```

`exports/scripts.json` records SHA-256 hashes of the scripts. The regular tests check the hashes
and decode every picture with the same bounds as Recent. The generated PNGs and hash file are
necessary shipped exports; benchmark screenshots and other review output stay outside the asset
tree.
